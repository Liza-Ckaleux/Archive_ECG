# Расчет признаков отклонения от плоскостности петель ВЭКГ

Этот проект предназначен для расчета признаков отклонения от плоскостности петель векторной ЭКГ (ВЭКГ) и обучения классификатора.

## Описание

Скрипт обрабатывает ЭКГ сигналы и рассчитывает следующие признаки:
- **11 признаков для петли QRS**: общий R² и 10 локальных R² для разных участков петли
- **11 признаков для петли P**: общий R² и 10 локальных R² для разных участков петли

**Итого: 22 признака на пациента**

Затем на этих признаках обучаются классификаторы для бинарной классификации.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### 1. Расчет признаков

Сначала необходимо рассчитать признаки из ЭКГ данных:

```bash
python process_ecg.py
```

Скрипт автоматически обработает файлы:
- `X_train.pkl` → `train_features.csv`
- `X_test.pkl` → `test_features.csv`

### 2. Обучение классификаторов

После расчета признаков можно обучить все классификаторы:

```bash
python train_all_models.py
```

Скрипт:
- Обучит все модели: Logistic Regression, Random Forest, SVM, MLP
- MLP использует валидацию для отслеживания loss и предотвращения переобучения
- Остальные модели обучаются на train целиком
- Все модели тестируются на test
- Каждая модель сохраняет результаты в свою папку

### 3. Проверка структуры данных

Перед запуском основного скрипта можно проверить структуру данных:

```bash
python check_data_structure.py
```

### 4. Тестирование на подмножестве

Для тестирования на небольшом подмножестве:

```bash
python test_processing.py
```

## Алгоритм обработки ЭКГ

1. **Предобработка ЭКГ сигналов**:
   - Приведение к нулевому среднему
   - Полосовой фильтр Баттерворта (0.6-40 Гц)

2. **Расчет ВЭКГ** по формулам:
   - x = -(-0.172*V1 - 0.074*V2 + 0.122*V3 + 0.231*V4 + 0.239*V5 + 0.194*V6 + 0.156*I - 0.01*II)
   - y = (0.057*V1 - 0.019*V2 - 0.106*V3 - 0.022*V4 + 0.041*V5 + 0.048*V6 - 0.227*I + 0.887*II)
   - z = -(-0.229*V1 - 0.31*V2 - 0.246*V3 - 0.063*V4 + 0.055*V5 + 0.108*V6 + 0.022*I + 0.102*II)

3. **Усреднение ВЭКГ** по 5 периодам

4. **Выделение петель**:
   - Петля QRS (большая петля)
   - Петля P (малая петля)

5. **Расчет R²** методом наименьших квадратов:
   - Общий R² для всей петли
   - 10 локальных R² для разных участков петли (каждая петля делится на 10 равных областей)

## Формат выходных данных

### Признаки (CSV файлы)
Результаты сохраняются в CSV файлы со следующими колонками:
- `QRS_R2_total` - общий R² для петли QRS
- `QRS_R2_region_1` до `QRS_R2_region_10` - локальные R² для петли QRS
- `P_R2_total` - общий R² для петли P
- `P_R2_region_1` до `P_R2_region_10` - локальные R² для петли P

### Результаты классификации
После обучения классификаторов создаются следующие папки:

**`features/`** - папка с признаками:
- `train_features.csv` - признаки обучающей выборки
- `test_features.csv` - признаки тестовой выборки

**`models/`** - папка с результатами всех моделей:
- `summary.csv` - сводная таблица метрик всех моделей
- `logistic_regression/` - результаты Logistic Regression:
  - `model.pkl` - обученная модель
  - `scaler.pkl` - скейлер
  - `metrics.csv` - метрики на тесте
  - `roc_curve.png` - ROC кривая
  - `confusion_matrix.png` - матрица ошибок
  - `feature_importance.png` - важность признаков
- `random_forest/` - результаты Random Forest (аналогично)
- `svm/` - результаты SVM (без feature importance)
- `mlp/` - результаты MLP:
  - Все вышеперечисленное
  - `loss_curve.png` - график loss по эпохам
  - `loss_history.csv` - история loss

## Требования к входным данным

Входные данные должны быть в формате pickle и содержать ЭКГ сигналы в одном из форматов:
- Словарь с ключами: 'V1', 'V2', 'V3', 'V4', 'V5', 'V6', 'I', 'II'
- Массив numpy с формой [patients, channels, time] или [patients, time, channels]
  (предполагается порядок каналов: I, II, V1, V2, V3, V4, V5, V6)

## Параметры

По умолчанию используется частота дискретизации 500 Гц. Если ваши данные имеют другую частоту, измените параметр `sfreq` в функции `process_dataset()`.

## Особенности моделей

- **Logistic Regression**: Feature importance на основе коэффициентов
- **Random Forest**: Feature importance на основе impurity
- **SVM**: Без feature importance (не интерпретируемо)
- **MLP**: Использует валидацию для отслеживания loss и предотвращения переобучения
