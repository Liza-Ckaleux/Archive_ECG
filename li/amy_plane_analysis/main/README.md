# Расчет признаков отклонения от плоскостности петель ВЭКГ

Проект предназначен для расчета признаков отклонения от плоскостности петель векторной ЭКГ (ВЭКГ) и обучения классификаторов

## Описание

Скрипт обрабатывает ЭКГ сигналы и рассчитывает следующие признаки:
- Признаки для петли **QRS**
- Признаки для петли **ST**
- Для каждой петли считаются характеристики в **5 точках**
- Для каждой точки используются **5 окрестностей**
- Также считается признак **total** для каждой петли

**Итого: 52 признака на пациента**

Затем на этих признаках обучаются классификаторы для бинарной классификации.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### 1. Расчет признаков

Сначала необходимо рассчитать признаки из ЭКГ данных:

```bash
python process_ecg.py
```

Скрипт автоматически обработает файлы:
- `X_train.pkl` → `train_features.csv`
- `X_test.pkl` → `test_features.csv`

### 2. Обучение классификаторов

После расчета признаков можно обучить классификаторы:

```bash
python classification/train_random_forest.py
python classification/train_svm.py
```

Скрипты:
- Обучают `Random Forest` и `SVM` на признаках из `features_<dataset_name>/`
- Масштабируют признаки (`StandardScaler`)
- Подбирают порог классификации по train через 5-fold CV (без утечки)
- Максимизируют F1 по precision-recall кривой
- Оценивают модель на test с фиксированным порогом
- Сохраняют результаты в `models_<dataset_name>/`

### 3. Проверка структуры данных

Перед обучением проверьте файл `config.yaml`:
- `dataset_name`: `amy`, `ph` или `lef`
- `dataset_type`: `original` или `stratified`
- `dataset_dir`: путь к директории с `y_train*.pkl` и `y_test*.pkl`

## Алгоритм обработки ЭКГ

1. **Предобработка ЭКГ сигналов**:
   - Приведение к нулевому среднему
   - Полосовой фильтр Баттерворта (0.6-40 Гц)

2. **Расчет ВЭКГ** по формулам:
   - x = -(-0.172*V1 - 0.074*V2 + 0.122*V3 + 0.231*V4 + 0.239*V5 + 0.194*V6 + 0.156*I - 0.01*II)
   - y = (0.057*V1 - 0.019*V2 - 0.106*V3 - 0.022*V4 + 0.041*V5 + 0.048*V6 - 0.227*I + 0.887*II)
   - z = -(-0.229*V1 - 0.31*V2 - 0.246*V3 - 0.063*V4 + 0.055*V5 + 0.108*V6 + 0.022*I + 0.102*II)

3. **Усреднение ВЭКГ** по 5 периодам

4. **Выделение петель**:
   - Петля QRS
   - Петля ST

5. **Расчет признаков отклонения от плоскостности**:
   - Для 5 ключевых точек
   - Для 5 окрестностей вокруг каждой точки
   - Плюс общий показатель (`total`) для каждой петли

## Формат выходных данных

### Признаки (CSV файлы)
Результаты сохраняются в CSV (всего 52 признака), включая:
- признаки для петли `QRS` (5 точек × 5 окрестностей + `total`)
- признаки для петли `ST` (5 точек × 5 окрестностей + `total`)

### Результаты классификации
После обучения классификаторов создаются следующие папки:

**`features_amy/`, `features_ph/`, `features_lef/`** - папки с признаками:
- `train_features.csv` - признаки обучающей выборки
- `test_features.csv` - признаки тестовой выборки

**`models_amy/`, `models_ph/`, `models_lef/`** - папки с результатами моделей:
- `random_forest/` - результаты Random Forest:
  - `model.pkl`, `scaler.pkl`
  - `metrics.csv`
  - `threshold.json`
  - `pr_curve.png`, `metrics_vs_threshold.png`, `confusion_matrix.png`
- `svm/` - результаты SVM:
  - `model.pkl`, `scaler.pkl`
  - `metrics.csv`
  - `threshold.json`
  - `pr_curve.png`, `metrics_vs_threshold.png`, `confusion_matrix.png`

### Подбор оптимального порога

Для `Random Forest` и `SVM` используется одинаковая схема:
- На train считаются out-of-fold вероятности через `StratifiedKFold(n_splits=5)`
- По кривой precision-recall перебираются пороги
- Выбирается порог с максимальным F1
- Порог сохраняется в `threshold.json` и затем применяется на test

## Требования к входным данным

Входные данные должны быть в формате pickle и содержать ЭКГ сигналы в одном из форматов:
- Словарь с ключами: 'V1', 'V2', 'V3', 'V4', 'V5', 'V6', 'I', 'II'
- Массив numpy с формой [patients, channels, time] или [patients, time, channels]
  (предполагается порядок каналов: I, II, V1, V2, V3, V4, V5, V6)

## Параметры

По умолчанию используется частота дискретизации 500 Гц. Если ваши данные имеют другую частоту, измените параметр `sfreq` в функции `process_dataset()`.

## Особенности моделей

- **Random Forest**: вероятности классов + подбор порога по F1
- **SVM (RBF)**: `class_weight='balanced'`, вероятности + подбор порога по F1
